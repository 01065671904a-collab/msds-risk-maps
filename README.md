# MSDS 유해화학물질 통합관리 웹사이트

로그인 없이 누구나 이용할 수 있는 공개형 MSDS 분석·통합관리 웹사이트입니다.

## 공개 및 데이터 처리 방식
- **소스코드 공개:** GitHub Public 저장소로 게시할 수 있습니다.
- **웹사이트 공개:** Render가 제공하는 `onrender.com` 주소로 누구나 접속할 수 있습니다.
- **로그인:** 필요하지 않습니다.
- **사용자 자료:** 제품 목록·성분·분석 결과는 각 사용자의 브라우저 `localStorage`에 저장됩니다. 서버 DB에 제품 목록을 저장하지 않으므로 사용자 간 목록이 공유되지 않습니다.
- **백업:** JSON 백업·복원, XLSX/PDF 내보내기를 지원합니다. 브라우저 데이터 삭제·기기 변경 전 백업이 필요합니다.
- **PDF 파일:** 분석을 위해 서버로 전송되며 영구 보관하지 않습니다. PDF 업로드는 IP별 요청 제한 및 20MB 크기 제한을 둡니다.
- **KOSHA API 인증키:** 서버 환경변수 `KOSHA_SERVICE_KEY`로 보관하며 브라우저에 전달하지 않습니다.

## Render 절전 시간과 요금
Render 무료 웹서비스는 **15분 동안 인바운드 요청이 없으면 절전**됩니다. 이 시간을 60분으로 설정하는 옵션은 무료 플랜에 없습니다. 절전 후 첫 접속은 서버가 다시 시작되므로 약 1분 정도 지연될 수 있습니다.

Render 유료 웹서비스는 유휴 상태에서도 절전되지 않습니다. 즉, 60분 후 절전되는 것이 아니라 계속 실행됩니다. Render 공식 가격표 기준 Starter는 **월 7달러부터**이며 요금·세금·환율은 결제 시점에 확인해야 합니다.

- 비용 없이 시험 운영하려면 `render.yaml`의 `plan: free`를 유지합니다.
- 절전 없이 운영하려면 Render 배포 후 서비스의 인스턴스 유형을 Starter로 변경합니다. 무료 플랜에서 60분 타이머를 설정하는 방식은 지원되지 않습니다.

## KOSHA API 개발계정 유의사항
공공데이터포털의 한국산업안전보건공단 MSDS 조회 서비스는 현재 안내상 개발단계 자동승인, 개발계정 일일 2,000회이며 운영단계는 별도 심의승인입니다. 공개 사이트에 개발계정 키를 연결해 시험할 수는 있지만, 불특정 다수가 사용하는 운영 서비스로 안정적으로 공개하기 전에는 공공데이터포털에서 운영계정 전환·트래픽 조건을 확인하고 신청하는 것을 권장합니다.

현재 서버의 기본 신규 CAS 조회 제한은 하루 250개입니다. CAS 1건당 목록 1회와 상세정보 최대 6회를 조회할 수 있어, 이 제한은 개발계정 일일 2,000회 한도 안에 여유를 두기 위한 초기 보호값입니다. 동일 CAS는 서버 메모리 캐시를 사용합니다. 서버 재시작 시 캐시와 카운터는 초기화됩니다.

공공데이터포털 API 상세: https://www.data.go.kr/data/15157612/openapi.do

## 배포 방법
1. GitHub에서 **Public** 저장소를 새로 만듭니다.
2. 이 프로젝트의 파일과 폴더를 저장소 루트에 업로드합니다. ZIP 파일 자체를 저장소에 올리는 것이 아니라 압축을 풀어 내부 파일을 올립니다.
3. Render 계정을 만들고 `New` → `Blueprint`에서 해당 GitHub 저장소를 선택합니다.
4. `render.yaml`을 적용합니다. 무료로 시작할 경우 `plan: free`를 유지합니다.
5. Render 서비스의 Environment 설정에서 `KOSHA_SERVICE_KEY`에 공공데이터포털의 일반 인증키(Decoding)를 입력합니다. 인증키를 GitHub 코드나 README에 올리지 마세요.
6. Deploy가 성공하면 생성된 `https://서비스이름.onrender.com` 주소를 누구나 이용할 수 있습니다.
7. 절전 없는 운영이 필요하면 Render 서비스 설정에서 인스턴스를 Starter로 변경합니다. 변경 전 가격과 결제 조건을 확인하세요.

## KOSHA API 연동 범위
- 목록: `GET /B552468/msdschem1/getChemList001`
- 상세: `getChemDetail011`, `getChemDetail021`, `getChemDetail031`, `getChemDetail081`, `getChemDetail091`, `getChemDetail151`
- API 응답 XML을 읽어 조회명, 유해성 정보, 물리화학 정보, 노출 관련 정보 및 법적 규제현황 원문을 제공합니다.
- KOSHA 자료는 MSDS 작성·검토 참고용이며 공급자 MSDS를 대체하지 않습니다.

## 정확성·보안상 한계
- PDF 표 추출은 문서 레이아웃에 따라 물질명·CAS·함유량을 잘못 묶을 수 있습니다. OCR 및 자동 추출 결과는 원본 MSDS와 대조해야 합니다.
- CMR 구분 1A/1B, 작업환경측정, 특수건강진단, 관리대상유해물질, 특별관리물질은 H-code만으로 확정하지 않습니다. 현행 법령 별표와 원문을 확인하고 근거가 불충분하면 `미확인`으로 둡니다.
- H-code 위험등급은 사용자가 제공한 이미지 기준을 그대로 적용합니다: 4등급(H340, H341, H350, H351, H360, H361, H362, H370), 3등급(H300, H301, H310, H311, H330, H331, H314, H318, H317, H334, H372, H373), 2등급(H302, H312, H332, H304, H371), 1등급(H315, H319, H320, H335, H336). 제품에 속한 구성성분의 H-Code 중 가장 높은 등급 하나를 제품 대표 위험등급으로 표시합니다. 이는 법정 위험성 평가 등급이 아닙니다.
- 공개된 서버의 API는 모든 익명 방문자가 공유합니다. IP별 호출 제한·하루 신규 CAS 조회 한도를 적용하지만, 무료 개발계정의 호출량과 서버 자원에 따라 일시적으로 조회가 제한될 수 있습니다.
- 사용자 목록은 브라우저에만 저장됩니다. 비밀번호나 민감정보를 입력하지 말고, 브라우저 프로필을 공유하는 환경에서는 사용을 주의하세요.
